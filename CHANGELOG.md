# Changelog

Every release of @latro/ops-ui, newest first (spec §4.3). Each section is `## X.Y.Z — date` with
`Added:` / `Changed:` / `Fixed:` / `Visible:` / `Breaking:` / `Upgrade steps:` lines; a major
names every pixel change (`Visible:`, per component) and the exact steps per app
(`Upgrade steps:`). The sync prints the sections between an app's version and the new one.

## 1.4.0 — 2026-10-01
Added: Input prefix / suffix (PrefabOps restyle plan M3 / G10, components/field.tsx): a unit or currency drawn inside the field before ("€") or after ("mm", "bar", "°C", "kg", "%") the value; muted text the pointer passes through to the input, aria-hidden and joined to the input's aria-describedby (after any the caller passes), so it is the field's description and never its value. The text keeps clear of an adornment by its measured width (12px edge + width + 6px; before the first measurement, the server render, an estimate of 0.6em per character). size md / lg and the touch floor apply to the adornment text too. className still styles the input box; the new wrapperClassName lays out the wrapper (default "relative block w-full") an adorned input gets. Added: YearInput (M3 / G13, components/year-input.tsx, client): DateInput's sibling for a year. Takes four digits (two are read as DateInput reads a two-digit year; anything unreadable snaps back when the field is left), posts the four-digit string under name through a hidden input and calls onChange({ target: { value, name } }) ("" when cleared); min / max (numbers) disable the years outside them and a typed year outside marks the field (aria-invalid + the datePicker.earliest / latest message); required hides Clear; read-only aware (disabled in a ReadOnlyScope unless readOnlySafe); size md / lg; the touch floor. Keyboard: ↓ enters the grid, ← → a year, ↑ ↓ a row, PageUp / PageDown a page (Shift: ten), Home / End the page's ends, Enter picks, Escape closes; Enter in the open field settles instead of submitting. lib/year-input.ts holds the pure rules (isYearString, parseTypedYear, maskTypedYear, yearWithin, yearPageStart, anchorYear, yearKeyTarget).

Fixed positioning, flip-up, follow-scroll, Escape and the outside press work the same for every shape; a menu with no room left of its button's right edge (a labelled trigger near the left edge) lines up with the button's left edge instead. Without trigger / sections the menu renders the 1.3.0 markup (tested against the 1.3.0 source; its baselines are unchanged). Types RowMenuSection, RowMenuTrigger.

Browser floor: color-mix() (Safari 16.2+, Chrome 111+, Firefox 113+). The brand tokens are var() indirections, so for a browser without color-mix() Tailwind cannot precompute an opacity-modified brand colour (bg-primary/10, ring-primary/25, bg-ink/40, the external Monogram's bg-external/10): its fallback there is the opaque token, where the apps' literal tokens degraded to a translucent tint. Tailwind v4's own floor (Safari 16.4, Chrome 111, Firefox 128) already lies above it, so no browser either app supports sees a difference.
Visible: none. 1.0.0 is a pure extraction: every story renders as the FinaOps kit (fina-ops 19aad88) it was taken from, which equals Workforce Ops' (bottom-sheet dialogs below sm, the touch calendar sheet, ExternalButtonLink); the extraction proof is docs/extraction-proof-1.0.0.md in the ops-ui repository (spec §12.1 L6).
Upgrade steps: none (the first release); each app adopts it through the steps of spec §12.2 (FinaOps F0-F7) and §12.3 (Workforce Ops W0-W8). Its globals.css scans the vendor folder and nothing else the adoption puts in the app tree (spec §8.4): the @source line plus one @source not line each for the vendored .md files, scripts/sync-ops-ui.*, ops-ui.config.json and ops-ui.lock.json (Tailwind's automatic detection reads root JSON, and a config lists token names), so neither a docs-only release nor a config edit changes the app's CSS or its token dump. Once globals.css imports the library tokens, the sync refuses an app @theme that declares anything but its listed extensions, a rule that sets a library token or a brand variable outside brand.css, and a missing brand.css import (spec §8.5 check 7).
